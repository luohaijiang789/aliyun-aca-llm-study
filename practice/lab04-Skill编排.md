# Lab 04 · 把一个工作流固化成 Skill

**对应**：Skill 编排
**模块**：大模型 Agent（16%）
**V2.4 状态**：🆕 **全新考点**

---

## 目标

把一个你重复在做的工作流程，固化成一个可复用的 Skill，并理解它和普通提示词的本质区别。

---

## 步骤

1. 挑一个你真实重复做 3 次以上的工作流（例：日志安全分析、周报生成、代码审计）
2. 拆解成明确步骤：输入 → 步骤 1 → 步骤 2 → … → 输出格式
3. 在 Agent 平台中把它配置为 Skill（待确认具体产品形态）
4. 用**不同的输入**调用同一个 Skill 两次，验证输出稳定性
5. 对比：同样的任务，用「一段提示词」做一次 vs 用「Skill」做一次，观察差异
6. 尝试组合两个 Skill 完成一个更长的任务（编排）

---

## 必须搞懂的考点

| 对比项 | 提示词 Prompt | Skill |
|---|---|---|
| 形态 | 一段指令文本 | **流程 + 工具 + 约束**的封装 |
| 复用 | 每次重新写/粘贴 | 一次定义，反复调用 |
| 稳定性 | 依赖每次表述 | 固化后输出稳定 |
| 能否含工具 | 一般不能 | ✅ 可绑定工具 |
| 适用场景 | 一次性、探索性任务 | **重复、有固定流程的工作方法** |

**一句话**：
> **Skill = 把"你做事的方法"变成"模型会做的事"。**

**编排**：多个 Skill 按流程串起来，完成单个 Skill 做不了的复杂任务。
