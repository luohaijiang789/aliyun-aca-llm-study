# Lab 05 · 给 Agent 加自检与重试

**对应**：自检闭环
**模块**：大模型 Agent（16%）
**V2.4 状态**：🆕 **全新考点**

---

## 目标

给 Agent 加一道「自己检查自己」的机制，理解它解决什么问题、以及它**不等于**什么。

---

## 步骤

1. 用 Lab 04 的 Skill 或 Lab 02 的桌面 Agent，跑一个会偶尔失败的任务
2. 记录**没有自检时**的失败率与失败形态
3. 加自检机制（三种方式任选或都试）：
   - **规则校验**：用代码/规则检查输出格式、必填字段
   - **反思提示**：让模型自己复查输出是否满足要求
   - **重试上限**：不合格则重跑，设最大次数防死循环
4. 对比加自检前后的成功率
5. 观察：自检**增加了什么成本**（时间、token、复杂度）

---

## 必须搞懂的考点

| 说法 | 判断 |
|---|---|
| Agent 执行后自己检查结果，不合格则修正/重试 | ✅ **正解** |
| 人工审核 Agent 每一步输出 | ❌ 人工流程，不是自检闭环 |
| 让模型生成 N 次挑最好的（best-of-N） | ⚠️ 不等于自检 —— 自检需要**校验标准** |
| 自检能完全消除幻觉 | ❌ 降低，不能消除 |
| 自检需要设重试上限 | ✅ 否则可能死循环 |

**为什么需要自检**：
> 单次大模型生成有**不可靠性**，自检闭环把「一次性赌运气」变成「有反馈的迭代」。

**代价**：延迟 ↑、成本 ↑、复杂度 ↑ —— 所以简单任务不必上。
