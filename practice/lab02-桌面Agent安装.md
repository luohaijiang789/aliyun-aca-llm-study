# Lab 02 · 安装桌面 Agent 并完成真实任务

**对应**：桌面 Agent / Agent 三能力（感知-思考-行动）
**模块**：大模型 Agent（16%）
**V2.4 状态**：🆕 **全新考点**

---

## 目标

在本地装一个桌面 Agent，让它完成一个**真实的多步任务**，观察它的感知/思考/行动全过程。

---

## 步骤

1. 使用当前已可用的桌面 Agent，或先纸上画出同一任务的感知、规划、工具和检查点；具体产品及下载入口以当前官方课程为准
2. 安装并完成初始化配置（模型、权限、工作目录）
3. 给一个真实任务，例如：
   - 「把这个文件夹里所有 PDF 的标题提取出来，整理成 Excel」
   - 「读这段代码，找出安全问题，输出报告」
4. **重点观察**：
   - 它如何**感知**（读了哪些文件/拿到了什么输入）
   - 它如何**思考**（有没有拆分步骤、有没有规划）
   - 它如何**行动**（调用了什么工具、改了什么文件）
5. 故意给一个模糊指令，观察它如何失败 —— 理解「任务描述清晰度」对 Agent 的影响

---

## 必须搞懂的考点

| 考点 | 要能回答 |
|---|---|
| Agent 三能力 | 感知（收信息）/ 思考（做规划）/ 行动（调工具） |
| 桌面 Agent vs 云端 Agent | 桌面 Agent 能操作**本地文件与终端** |
| 什么时候用 Agent | 任务复杂、多步骤、需调外部工具 |
| 什么时候不用 | 简单单轮问答 → 提示词就够了，Agent 是过度设计 |
| ReAct | Reasoning + Acting **交替**循环 |
| CoT / ToT | 思维链 / 思维树，是**思考**环节的方法 |
