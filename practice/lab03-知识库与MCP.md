# Lab 03 · 给 Agent 接知识库 + MCP 工具

**对应**：知识库应用 / MCP 协议 / Function Calling
**模块**：大模型 Agent（16%）
**V2.4 状态**：🆕 **全新考点**

---

## 目标

让 Agent 既能查私域知识（知识库），又能调用外部工具（MCP），理解两者的区别。

---

## 步骤

1. 在 Agent 中接入 Lab 01 建好的知识库
2. 测试：问一个只有知识库里才有的内容 → 验证 Agent 会去检索
3. 配置一个 MCP Server / MCP 工具（待确认百炼支持形态）
4. 测试：给一个需要调用外部工具的任务（如查数据、操作文件）
5. **对比观察**：
   - 走知识库时，Agent 的行为是「检索 → 阅读 → 回答」
   - 走 MCP 时，Agent 的行为是「构造调用 → 执行 → 拿结果」
6. 观察 Function Calling 的实际形态：模型输出的是**结构化的调用请求**，不是自然语言

---

## 必须搞懂的考点

| 概念 | 层级 | 一句话 | 易错 |
|---|---|---|---|
| **Function Calling** | 模型能力 | 模型输出「我要调这个函数 + 参数」 | 不是插件，是底层能力 |
| **MCP** | **协议标准** | 标准化模型与外部数据源/工具的**连接方式** | ❗ 是"协议"，不是工具本身 |
| **知识库** | 数据 | 提供**私域知识**给检索 | 补**知识** |
| **插件** | 能力封装 | 把外部能力包装成可调用成品 | 补**能力** |

**辨析核心**：
- 知识库 → 补 **知识**（模型不知道的东西）
- MCP / 插件 → 补 **能力**（模型做不到的事）
- MCP 是**怎么连**的标准，插件是**连了什么**的成品
