## 二、Qwen 回答（正文全文）

为您收集并整理了**阿里云大模型工程师ACA（助理工程师）认证**的最新备考资料、考试大纲及核心知识点。该认证主要面向非技术背景人员、无算法背景的工程技术人员和初学者，旨在帮助考生掌握大模型的使用方法并提升工作效率。

以下是详细的资料收集与备考指南：

### 一、认证基本信息

- **认证费用**：600元人民币
- **考试机会**：每个订单包含2次考试机会（首次未通过需等待24小时方可进行第二次考试），订单自购买之日起一年内有效
- **考试形式**：50道选择题（包含单选和多选），满分100分，80分及格
- **认证流程**：课程学习 ➔ 实验练习 ➔ 模拟自测 ➔ 认证考试 ➔ 领取证书

### 二、官方课程与考试大纲 (V2.4版)

官方课程共分为3章，包含11个核心课时：

- **第1章：认识大模型**
  - 课时1：认识大模型（定义、工作原理、分类）
  - 课时2：大模型的典型应用场景
- **第2章：用好大模型（核心考点）**
  - 课时3：通过优化输入（提示词工程）来提升回答质量
  - 课时4：通过 RAG（检索增强生成）增强大模型回答原本无法回答的问题
  - 课时5：通过微调改善大模型在垂直领域的表现
  - 课时6：安装桌面 Agent，开始用它干活
  - 课时7：让 Agent 接入知识库和工具
  - 课时8：用 Skill 固化你的工作方法
  - 课时9：给 Agent 加一道自检闭环
  - 课时10：大模型应用的安全合规
- **第3章：拓展与总结**
  - 课时11：学习总结与回顾

### 三、核心备考知识点速览

1. **大模型训练三阶段**
   - 预训练（Pre-training）：在大规模数据上进行无监督训练，学习通用知识
   - 监督微调（SFT）：使用高质量标注数据进行有监督训练，使模型学会遵循指令
   - 对齐偏好（RLHF）：通过人类反馈强化学习，使模型输出更贴近人类价值观和偏好

2. **技术选型决策树（必考场景题）**
   - 回答不够好 ➔ 优先**优化提示词**（成本最低）
   - 缺少私域/最新领域知识 ➔ 使用 **RAG**
   - 需要特定的输出格式/行文风格 ➔ 使用 **微调**
   - 任务复杂、需要多步执行或调用外部API ➔ 使用 **Agent**
   - 模型本身能力边界不足 ➔ 加装 **插件**

3. **Agent 三大核心能力**
   - 感知（Perception）：获取环境信息和用户输入
   - 思考（Reasoning）：分析信息、制定计划、做出决策（CoT / ReAct）
   - 行动（Action）：执行具体操作、与外部工具交互

4. **阿里云大模型产品矩阵**
   - 通义千问（Qwen）：基础语言大模型
   - 通义万相：视觉生成模型（文生图/视频）
   - 百炼平台：一站式大模型服务与应用开发平台

### 四、备考资源推荐

### 五、进阶建议

ACA 定位是「用AI」（通识与应用），不涉及复杂数学公式与算法推导。有开发基础或想做底层研发，建议继续考 ACP（「造AI」，含云端实操环节）。
