# 题库

> 自建题库。来源分三类，务必在题目标注，**可信度不同**。

---

## 来源与可信度

| 标记 | 含义 | 可信度 |
|:---:|---|:---:|
| `[官方]` | 来自官方课程/模拟自测/大纲 | ⭐⭐⭐ 最高 |
| `[自编]` | 根据知识地图考点自行编写 | ⭐⭐ 中（可能与实际考法有偏差） |
| `[转载]` | 来自网络/第三方 | ⭐ 低，需交叉验证 |

## 用法

1. 按模块做题，不要打乱顺序 —— 同一模块连续做能强化记忆
2. 错题抄进「错题本」，注明**错因**（记错了 / 概念混淆 / 没看清题）
3. 错因是「概念混淆」的，回填 `../docs/04-易错辨析速查.md`
4. 目标：每个模块正确率 ≥ 85% 再进下一个
