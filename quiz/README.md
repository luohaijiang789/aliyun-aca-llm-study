## 用法

1. **按模块做**，不要打乱顺序 —— 同模块连做强化记忆
2. 每个模块题库自带「**出题覆盖自检表**」—— 先确认考点没漏
3. 做错的抄进 [错题本](错题本.md)，注明**错因**（A记错 / B概念混淆 / C没看清题 / D过度推断 / E场景判断错）
4. 错因是「概念混淆」的，回填 `docs/04-易错辨析速查.md`
5. 目标：每模块正确率 ≥ 85% 再进下一个
