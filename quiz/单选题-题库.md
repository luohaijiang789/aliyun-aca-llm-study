### Q001 [大模型概念] [自编] 单选

大模型训练的三个阶段，按正确顺序排列是：

- A. SFT → 预训练 → RLHF
- B. 预训练 → SFT → RLHF
- C. 预训练 → RLHF → SFT
- D. RLHF → 预训练 → SFT

**答案**：B
**解析**：预训练学通用知识（基座）→ SFT 学遵循指令 → RLHF 对齐人类偏好。
**考点**：01-知识地图 → M1 → 训练三阶段
**我错了吗**：☐

### Q002 [大模型概念] [自编] 单选

关于 RLHF 的作用，正确的说法是：

- A. 让模型学习新知识
- B. 让模型输出更符合人类价值观和偏好
- C. 让模型学会遵循指令
- D. 减少模型参数量

**答案**：B
**解析**：A 是预训练，C 是 SFT。RLHF 不注入新知识，只调整输出倾向。
**考点**：01-知识地图 → M1 → 训练三阶段
**我错了吗**：☐

### Q003 [增强应用能力] [自编] 单选

公司上周刚更新的退货政策，客服机器人不知道。最合适的解决方式是：

- A. 用新政策数据微调模型
- B. 使用 RAG 接入政策文档
- C. 优化提示词
- D. 更换更大的模型

**答案**：B
**解析**：缺**最新/私域知识** → RAG。微调进去的知识会立刻过时且不可追溯。
**考点**：03-技术选型决策树
**我错了吗**：☐

### Q004 [增强应用能力] [自编] 单选

需要模型查询「当前实时股价」，应采用：

- A. RAG
- B. 微调
- C. 插件
- D. Agent

**答案**：C
**解析**：实时外部能力属于模型**能力边界之外** → 插件。RAG 只能查你自己喂进去的静态知识库。
**考点**：03-技术选型决策树
**我错了吗**：☐

### Q005 [大模型微调] [自编] 单选

LoRA 微调的核心思想是：

- A. 重新训练全部参数
- B. 只训练低秩适配的小部分参数，大幅降低显存需求
- C. 增加模型层数
- D. 用更少的训练数据替换预训练

**答案**：B
**解析**：LoRA = Low-Rank Adaptation，冻结原权重，只训练低秩矩阵。QLoRA 再加量化。
**考点**：01-知识地图 → M5 → 微调方式

### Q006 [大模型微调] [自编] 单选

以下哪种场景**最适合**使用微调？

- A. 模型不知道公司内部的会议纪要
- B. 需要模型每次都以「法务合规部」的固定口吻撰写对外回复
- C. 需要查询今天的天气
- D. 模型回答过于笼统，缺乏细节

**答案**：B

**考点**：03-技术选型决策树

### Q007 [大模型Agent] [自编] 单选

MCP（Model Context Protocol）的本质是：

- A. 一种大模型微调方法
- B. 一种用于标准化模型与外部数据源/工具连接的协议
- C. 一个具体的外部工具
- D. 一种提示词优化框架

**答案**：B

**考点**：01-知识地图 → M4 → 工具调用；04-易错辨析 → MCP/Skill/插件

### Q008 [大模型Agent] [自编] 单选

Agent 的三大核心能力是：

- A. 输入、处理、输出
- B. 感知、思考、行动
- C. 检索、生成、评估
