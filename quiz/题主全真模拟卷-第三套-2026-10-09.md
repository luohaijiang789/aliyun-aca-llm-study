## 全卷分析

### 一、这套卷重点考了什么

1. **RAG 必须分层排障**：知识是否存在（Q1、Q23、Q31）、解析是否保真（Q7）、切分是否保留结构（Q3、Q24）、检索方式是否匹配查询（Q27）、召回后是否有业务验收（Q28）。
2. **Prompt 的关键不是“多写”，而是给边界**：术语表（Q2）、模糊案例与分类依据（Q4）、角色与论证框架（Q5）、正反风格样例（Q25）、分析维度与待确认项（Q22）。
3. **微调解决稳定行为，RAG 解决新知识**：分类、意图、术语和固定语气可训练（Q8、Q12、Q15、Q18、Q29、Q37）；最新政策和动态信息应接知识库或工具（Q23、Q26、Q37C）。
4. **Agent 的价值在流程、工具和闭环**：Skill 固化工作流（Q9、Q13、Q21），工具承担精确计算和事实查询（Q10、Q32、Q45），浏览器验证真实产物（Q33），过程记录支持审计（Q16）。
5. **高风险动作必须由人负责**：医疗建议（Q17、Q34）、合同与法务结论（Q20、Q30）、付款（Q44）、金融业务办理（Q46）、外发报告（Q50）。

### 二、12 道错题反映的四类问题

#### 1. 没有先定位故障层：Q1、Q7、Q24

- Q1 是**源知识缺失**：先补知识条目和评测集。
- Q7 是**解析破坏表格结构**：先修解析，后谈召回和重排。
- Q24 是**切分破坏 API 小节完整性**：按结构切分，召回时补所属上下文。

记忆顺序：**源数据 → 解析 → 切分 → 索引 → 召回 → 重排 → 生成 → 业务验收**。前一层丢失的信息，后一层通常救不回来。

#### 2. 把流程或自检当成明确标准：Q2、Q4、Q22

- 固定术语：给对照表，不要只让模型“想清楚”。
- 相邻类别混淆：补边界案例，不要只补最典型样例。
- 开放式审查：先列分析维度、事实字段和待确认项，不要先给空表格。

一句话：**有标准就直接给标准；缺框架就先建框架；有边界混淆就补边界样例。**

#### 3. 混淆 Skill、资料库和微调：Q12、Q13

- Skill 保存可重复的步骤、结构、规则和检查项。
- 知识库保存事实、制度、历史资料和实时更新内容。
- 微调用标注样本改变稳定行为，适合低延迟分类、固定语气和领域意图。

#### 4. 多选题仍会选“听起来有帮助但越界”的项：Q36、Q41、Q43、Q50

- Q36B：AI 可以辅助战略研究，但让它直接给投资建议和预算不适合首批试点。
- Q41B：从报告抽取信息属于大模型基本能力，不能因为任务含“市场分析”就排除。
- Q43C：围绕既定结论找材料属于确认偏误。
- Q50B：让模型生成引用会扩大幻觉风险。

多选判断法：逐项问四句——**是否直接解决题干问题？是否需要题外前提？是否扩大权限或责任？是否出现“精确、直接、自动、保证”等过强承诺？**

### 四、考前需要新增记住的 12 句

1. 新知识缺失：补知识条目，同时补意图评测集。
2. 表格参数答错：先检查解析是否保留表头、字段和行列关系。
3. 技术文档被切散：按章节或 API 小节切分，召回时带父级上下文。
4. 相邻类别不稳定：补模糊边界案例和清晰判定依据。
5. 固定术语翻译：给术语对照表，优先于角色、CoT 和泛化自检。

8. 最新政策与动态信息：更新知识库或接实时工具，不靠偏好训练记忆。
9. 企业 AI 试点优先选高频、可复核、责任边界清楚的辅助任务。
