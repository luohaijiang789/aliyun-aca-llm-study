## 一、单选题（6 题）

### Q001 [M1-K03] [A] 单选

某团队计划把大模型接入报销初审流程，设计方案是：由大模型读取单据后**直接给出"通过/驳回"的最终结论并自动生效，无需任何人查看**。关于这一方案，下列说法正确的是：

- A. 可行。只要把报销规则写清楚，模型的判断就可以等同于审核人的决定
- B. 不可行。大模型可以辅助整理、归纳和给出参考意见，但**不能直接替人决定是否通过**，最终决定须由责任人作出
- C. 可行。只要用微调让模型学会公司报销规则，就可以取消全部人工环节
- D. 不可行。因为大模型完全不具备理解单据内容的能力，连辅助整理都做不到

**答案**：B

**考点**：M1-K03 不能直接替人决定什么（官方原文：「理解大模型是什么，能做什么，**不能直接替人决定什么**」）

**解析**：
- A ❌ 把"能输出答案"当成"能拍板"。官方原文明确要求理解大模型「**不能直接替人决定什么**」——决定权、签字权、发布权始终属于人。把规则写清楚只能提升输出质量，不能改变这一边界。
- B ✅ 准确对应官方原文。大模型的角色是**产出候选与参考**：可以生成草稿、整理要点、给出建议；但"是否通过"属于最终决定，须由责任人作出。官方在高风险场景的配套要求是「AI 可以辅助整理和起草，但**不能替代最终责任人**」，Agent 场景亦规定「**高风险动作必须人工确认**」。
- C ❌ 微调的作用是**稳定行为、格式、风格、分类能力或支持轻量模型部署**（官方 M5 原文），它**无法消除幻觉与概率性**，更不能把"最终责任"转移给模型，题干中"取消全部人工环节"的做法错误。
- D ❌ 走向另一个极端。大模型**能够**理解和处理单据文本，做辅助整理、要点提取、异常提示正是它的强项。问题不在于"能不能读懂"，而在于"能不能直接替人决定"。

**我错了吗**：☐

### Q002 [M1-K06] [A] 单选

客服同学问大模型"**本月初刚发布的产品退换货新政**有哪些变化"，模型给出了格式工整的答复，但与公司最新文件不符。技术同事建议把最新政策文件放进知识库，让模型基于检索到的资料回答。造成上述问题的原因是：

- A. 模型的**幻觉**：模型一定会因为缺乏自信而编造出不存在的政策条款
- B. 模型的**训练数据时间范围**限制：它的知识停留在训练数据截止时点，不了解此后新发布政策的真实内容
- C. 模型的**上下文限制**：政策文件字数太多，模型读不到后半部分
- D. 分词错误：政策中的术语被切成了错误的 Token，导致语义理解偏差

**答案**：B

**考点**：M1-K06 训练数据时间范围（官方原文：由此带来的「**幻觉、训练数据时间范围和上下文限制**」）

**解析**：
- A ❌ 错在点因。题干的核心是"本月初刚发布"——信息在模型训练之后才产生，这是**训练数据时间范围**问题。此外"一定会编造"表述过于绝对，且与事实不符。
- B ✅ 完全对应官方原文。模型的知识来自训练时见过的数据，**停留在训练数据截止时点**，训练完成后不会自动更新，因此不知道此后新发生的事；若强行作答，就容易给出过时或与事实不符的答案。正确做法是**接入知识库**，让模型基于最新资料回答——这正是 M3 的定位。
- C ❌ 题干并未出现"超长文档""粘贴不进去""前面内容被忽略"等上下文受限特征；模型正常接收了提问并作答，症结在于**知识过期**而非**装不下**。注意区分：**不知道新发生的事 = 时间范围；一次塞不下/前面被忘 = 上下文限制**。
- D ❌ 分词属背景知识，且官方 M1 未将其列为考点；即便个别术语切分不理想，也不会导致"整个政策都不知道"，与题干无关。

**我错了吗**：☐

### Q003 [M1-K07] [A] 单选

业务同学把一份约 50 万字的项目标书**一次性全部**粘贴给大模型，并要求"依据原文回答所有条款问题"。结果发现：对排在**开头**的条款能正常作答，对排在**中后部**的条款几乎无法回答。对此最合理的判断与处理是：

- A. 属于**训练数据时间范围**限制：标书写得太久远，模型没见过这些条款，只能通过微调注入
- B. 属于**上下文限制**：一次能处理的 Token 总量有上限，超长材料会被截断或不被同等重视；应先拆分处理，或通过知识库检索把相关片段放入上下文
- C. 属于**幻觉**：模型对中后部条款进行了编造，应要求它"再多检查两遍"即可解决
- D. 属于模型"拒绝回答"：只要在提问中加上"必须回答"的要求，就不会再遗漏

**答案**：B

**考点**：M1-K07 上下文限制（官方原文：由此带来的「幻觉、训练数据时间范围和**上下文限制**」）

**解析**：
- A ❌ 错判。题干材料已经**提供给模型**了（模型读得到开头部分），问题不是"没见过"，而是"装不下"。此外知识过期问题首选知识库而非微调，微调知识同样会过期。
- B ✅ 准确命中官方原文。模型**一次能处理的 Token 总量有上限**（输入 + 输出合计），超长材料要么被截断、要么超出部分不被有效处理。可行处理办法有三条：**拆分分段处理**（分段摘要再汇总）、**检索取相关片段**放入上下文、精简上下文并把关键信息放在当前问题附近。
- C ❌ 题干描述的是"无法回答"，并非"编造内容"，不属于幻觉；且让模型"再检查两遍"并不能突破上下文上限。
- D ❌ 这不是拒答问题，而是**输入容量**问题。加上强硬措辞既不能扩展上下文窗口，也不能保证输出可靠。

**我错了吗**：☐

### Q004 [M1-K05] [A] 单选

三个同事反馈了各自遇到的问题：① 用大模型做产品手册问答时，它给出了"该型号通过国家 XX 认证"的说明，但技术部门核查后确认**该认证从未存在过**；② 问"上一季度刚更新的内部售后标准"，模型给出的是**两年前的旧版本**；③ 一次性粘贴整本手册后提问，模型**完全没有读到最后三章的内容**。按官方对大模型局限的表述，三者依次对应：

- A. ① 幻觉　② 上下文限制　③ 训练数据时间范围
- B. ① 幻觉　② 训练数据时间范围　③ 上下文限制
- C. ① 训练数据时间范围　② 幻觉　③ 上下文限制
- D. ① 上下文限制　② 训练数据时间范围　③ 幻觉

**答案**：B

**考点**：M1-K05 / K06 / K07 三大局限辨析（官方原文：**幻觉、训练数据时间范围和上下文限制**）

**解析**：
- A ❌ ② 与 ③ 说反了。"给出两年前的旧版本"是知识**停在训练数据截止时点** → 训练数据时间范围；"完全读不到最后三章"是**一次装不下** → 上下文限制。
- B ✅ 三项全部对应正确，判据是官方原文的关键词：**① 编造出看似合理但与事实不符的内容（从未存在过的认证）= 幻觉**；**② 不了解训练截止后新发生的更新 = 训练数据时间范围**；**③ 一次性处理的总量有上限、超长材料不被处理 = 上下文限制**。
- C ❌ ① 与 ② 说反了。① 的特征是"**从未存在过**"（编造），不是"过期"。
- D ❌ 三项全部错位。记忆口诀：**「编的是幻觉，缺的是时间，塞不下的是上下文」**。

**我错了吗**：☐

### Q005 [M1-K08] [A] 单选

下列四项任务中，按照官方关于**能力边界**的表述，**最适合直接交给大模型完成**（即直接由模型生成、总结、分析，不必额外接知识库或调用工具）的是：

- A. 查询公司仓库此刻的实际库存余量，并据此执行锁定库存操作
- B. 依据本月刚更新的内部价格表，向客户报出准确的新报价
- C. 把已提供的访谈记录整理成 500 字要点，并归纳出三个主要观点
- D. 核算某客户的本年度授信额度，并把结果写入业务系统

**答案**：C

**考点**：M1-K08 能力边界判断（官方原文：掌握**能力边界判断**：什么时候适合**生成、总结、分析**，什么时候需要知识库、工具或人工确认）

**解析**：
- A ❌ 既需要**实时数据**（此刻库存），又要**执行业务动作**（锁定库存）。官方判据：需要实时数据、确定性计算或**业务动作**时应**调用工具**，不应由模型凭生成完成。
- B ❌ 报价依赖"本月刚更新的价格表"——这是**训练数据时间范围之外的新信息**，且金额要求精确。应**接入知识库**取最新资料，必要时用**工具**完成确定性计算；直接让模型生成有出错风险。
- C ✅ 完全符合官方"适合**生成、总结、分析**"的情形：材料**已在上下文中**（访谈记录已提供），任务是**压缩提炼 + 归纳观点**，属于纯文字的总结与分析，不涉及外部事实、实时数据或执行动作。
- D ❌ 授信额度属于**高风险**决策，且要**写入业务系统**（业务动作）。官方明确「AI 可以辅助整理和起草，但**不能替代最终责任人**」，此类结果应由工具/业务系统按规则计算，并**保留人工确认**。

**我错了吗**：☐

### Q006 [M1-K08] [A] 单选

某电商团队要上线"客户问价机器人"，需求包括：① 获取**当前实时**价格；② 按公司固定的**阶梯折扣规则算出精确金额**；③ 经确认后**写入报价单**。按照官方给出的能力边界方法，最合适的做法是：

- A. 只做提示词优化：把阶梯折扣规则写进提示词，由模型自己按规则生成最终金额
- B. 用微调把公司折扣规则训练进模型，由模型直接给出最终金额并写入报价单
- C. 由**工具**获取当前价格并完成确定性计算与写单动作，大模型负责理解意图、组织答复；规则性、确定性部分不交给概率生成
- D. 用上下文学习，每次提问时附上几个报价示例，模型就能保证金额与库存始终准确

**答案**：C

**考点**：M1-K08 能力边界判断（官方原文：什么时候需要**知识库、工具或人工确认**；M3 原文：需要实时数据、确定性计算或业务动作时用工具）

**解析**：
- A ❌ 优化输入能改善表达与组织，但**不能替模型拿到实时价格、也不能保证精确算术**。金额属于确定性计算，交给逐 Token 的概率生成有误报风险。
- B ❌ 混淆了微调的定位。官方 M5 原文：微调适合**稳定行为、格式、风格、分类能力，或支持轻量模型部署**；它是"稳行为"手段，不是"补实时数据/做精确计算/替人执行动作"的手段。
- C ✅ 精准命中官方判据：**实时数据**（当前价格）、**确定性计算**（阶梯折扣金额）、**业务动作**（写入报价单）都应交给**工具 / 业务系统**；大模型负责擅长的部分——理解意图、组织语言、解释口径。这是官方「**做动作靠工具**」的典型应用。
- D ❌ 上下文学习（ICL）只是给示例做示范，**不改参数、也不获取外部数据**；示例再多也不能保证实时金额与库存准确，且成本高、不可靠。

**我错了吗**：☐

### Q007 [M1-K01] [A] 多选

关于大模型之"大"的体现，下列说法正确的有：（多选）

- A. 模型参数规模巨大
- B. 训练数据的规模巨大
- C. 训练所需的算力投入巨大
- D. "大"意味着它能处理任意长度的输入，且回答必然正确、不受训练数据时间范围影响

**答案**：A、B、C

**考点**：M1-K01 大模型定义与"大"的体现

**解析**：
- A ✅ 参数量是模型承载知识与模式的"容量"，是"大"的首要体现。
- B ✅ 训练数据规模巨大，模型才具备通用的语言理解能力与世界知识。
- C ✅ 大规模参数与海量数据必然对应巨大的算力投入，这是"大"的成本面。三者共同支撑能力跃迁。
- D ❌ **过度外推，三处错误**：① "大"不意味着输入长度无上限——官方原文点明的局限之一就是**上下文限制**，一次能处理的 Token 总量有上限；② 规模增大只能**缓解**而非根除**幻觉**，不能保证"必然正确"；③ 模型知识仍受**训练数据时间范围**限制，不会因参数变大而自动获得最新信息。这类把"规模大"等同于"没有边界"的说法是标准错误项。

### Q008 [M1-K02 / M1-K03] [A] 多选

关于"大模型能做什么、不能直接替人决定什么"，下列说法正确的有：（多选）

- A. 适合承担**生成、总结、分析**类文本任务，产出草稿、候选方案与要点归纳
- B. 在医疗、金融、合同、对外发布等场景中，可以**辅助整理和起草**，但**不能替代最终责任人**
- C. 遇到高风险动作与最终决策时，应**保留人工确认**，不宜由模型自动生效
- D. 只要在提示词中写明"请务必准确，出错由你负责"，模型就可以承担最终责任并替人决定是否通过

**答案**：A、B、C

**考点**：M1-K02 能做什么 ＋ M1-K03 不能直接替人决定什么

**解析**：
- A ✅ 官方原文：掌握能力边界判断，明确"什么时候适合**生成、总结、分析**"。写文案、做纪要、归纳观点、给出候选方案，正是大模型最合适也最擅长的部分。
- B ✅ 官方 M6 原文：「AI 可以**辅助整理和起草**，但**不能替代最终责任人**」。注意"辅助"与"替代"的分界——整理、起草可以做，最终拍板不行。
- C ✅ 官方 M4 原文：「**高风险动作必须人工确认**」。此外官方把"保留人工确认"列为可选手段之一，是能力边界判断的兜底答案。
- D ❌ 三个错误：① 提示词缓解不了**幻觉**与**训练数据时间范围**两类固有局限；② 大模型没有责任主体，**"负责"在技术上和法律上都不成立**；③ 是否通过、是否签署、是否发布决定权属于人，这恰恰是官方"**不能直接替人决定什么**"所划的边界。

**我错了吗**：☐

### Q009 [M1-K09] [A] 多选

按照大模型的典型应用场景划分与能力边界判断，下列任务处理方式的对应关系，正确的有：（多选）

- A. 把一份 20 页的调研报告压缩成 300 字要点 → **文本摘要与信息提取**，可直接交给模型完成
- B. 把中文版产品说明翻译成英文版 → **文本润色与转换**，可直接交给模型完成
- C. 依据本月刚更新的内部价格表向客户报出精确金额 → 直接让模型生成，无需知识库、工具或人工确认
- D. 从合同文本中提取甲乙方、金额、付款期限 → **文本摘要与信息提取**，原文提供后可直接交给模型完成

**答案**：A、B、D

**考点**：M1-K09 典型应用场景（4 类）＋ M1-K08 能力边界判断

**解析**：
- A ✅ "20 页 → 300 字"是典型的**长度压缩**，属于**文本摘要与信息提取**（不是"润色转换"——润色只改说法、不压缩内容）。材料已提供、无外部事实依赖，可直接交给模型。
- B ✅ 翻译属于已有内容**换一种形式**输出，归**文本润色与转换**（不是"生成创作"——创作是从无到有）。
- C ❌ 精确金额 + 本月刚更新的价格表，触发两条能力边界：一是信息在**训练数据时间范围**之外，二是**确定性计算**要求精确。应**接入知识库**取最新价格表，必要时用**工具**完成计算，并对关键结果**保留人工确认**；不能图省事直接让模型生成。
- D ✅ 从原文中**抽取已有字段**属于**文本摘要与信息提取**（不是"信息推理与表格解读"——推理要基于数据给出新判断/结论；抽字段没有产生新结论）。原文已在上下文中时，可直接交给模型完成。

**我错了吗**：☐

### 做题时的三条抓手（官方原文）

1. **「理解大模型是什么，能做什么，不能直接替人决定什么。」** → 决定权永远在人。
2. **「幻觉、训练数据时间范围和上下文限制。」** → 编的是幻觉，缺的是时间，塞不下的是上下文。
3. **「优化输入、接入知识库、调用工具、使用微调、协作 Agent，或保留人工确认。」** → 场景题的标准答案池，**查知识用 RAG，做动作靠工具，稳行为才考虑微调**。
