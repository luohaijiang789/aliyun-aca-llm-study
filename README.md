# 阿里云大模型工程师 ACA 认证 · 复习体系

> 基于 **V2.4 官方考纲** 构建的体系化备考仓库。
> 目标：不只过 80 分，而是建立一套能迁移到实际工作的大模型应用知识框架。
>
> 考试形式与六模块权重已按官方《考试大纲》PDF 核对。原文见 [`docs/00-考试大纲-V2.4-官方原文.md`](docs/00-考试大纲-V2.4-官方原文.md)。深度资料中的场景例子与口诀是复习归纳，不等于官方承诺出题方式。

## 现在怎么复习（两套真题资料诊断后）

1. 查 [100 题逐题考点索引](docs/09-两套真题100题考点索引.md)，把自己的错题与重复/争议题定位到模块。
2. 读 [通关手册](docs/08-两套模拟卷通关手册.md)背官方数字与选型规则，再按[六模块真题复习卡](docs/10-六模块真题复习卡.md)补完整知识。
3. 做 [20 道错因专项](quiz/07-两卷错因专项练习.md)和 [12 道遗漏考点专项](quiz/08-真题遗漏考点专项练习.md)，再完成[六个离线场景](practice/lab06-真题场景决策演练.md)。
4. 回看[第一套](quiz/题主全真模拟卷-2026-10-09.md)与[第二套](quiz/题主全真模拟卷-第二套-2026-10-09.md)的错题解析；最后用未见过的卷限时检验。

两套是用户购买并确认为真题资料的「题主」全真卷；官方原题来源未独立核验。按记录推算分别为 66、74 分；多选分别为 4/15、8/15，是当前补分重点。第二套 Q1/Q28 重复、Q44/Q50 近似题却给出不一致的第二正确项；请按数据类型和题干条件判断。考试形式与权重以[官方 PDF](resources/官方-考试大纲-V2.4.pdf)为准。下方深度资料按需查阅。

```
📜 官方原文（逐字引用官方考试内容原文 + 原文↔章节对照表）
   ↓

   ↓

   ① 一句话定义  ② 是什么  ③ 为什么  ④ 怎么做/怎么用（含具体示例）
   ⑤ 易错点（❌误解 → ✅正确）  ⑥ 考法提示（干扰项陷阱在哪）  ⑦ 记忆锚点
   ↓

   ↓

   ↓

```

### 每道题的统一结构（四段式解析）

```
答案 → 考点 → 官方依据（引官方原文，或标注 [C] 级待核实）
   → 解析（A/B/C/D 逐项说明对/错，错项指出它对应什么真实误解）
   → 举一反三（这个考点还可能怎么变着考）
   → 易错提醒（最容易误选哪个、为什么）
   → 我错了吗 ☐
```

1. 读 [`docs/00-考试基准-V2.4.md`](docs/00-考试基准-V2.4.md) —— 5 分钟，搞清楚权重

## ⚠️ 三个已知坑（建库时已排查）

### 1. 网传笔记的课时编号是旧版

`Aliyun-ACA-LLM-Study-Summary`（2026-05，GitHub 6 stars）用的课时结构与 V2.4 **完全错位**：

| 课时 | 旧版笔记 | V2.4 官方 |
|:---:|---|---|
| 3 | API 调用 | **提示词优化** |
| 5 | 插件 | **微调** |
| 6 | RAG | **桌面 Agent** |
| 8 | 智能体 | **Skill 编排** |
| 9 | 安全合规 | **自检闭环** |
| 10 | 多模态 | **安全合规** |

→ 知识点可用，**编号不能照抄**。详见 [`docs/02-课时与学习路径.md`](docs/02-课时与学习路径.md)。

### 2. 网传资料缺 V2.4 全部新增考点

桌面 Agent、知识库应用、MCP、Skill 编排、自检闭环、RAG 评测归因、向量检索 —— 旧笔记里**一个都没有**。
而这些正好是本次提分最多的部分（Agent +6%）。

### 3. 「多模态大模型」已不再单独考核

旧资料仍将多模态列为独立模块（原 6%）；V2.4 已并入相关章节。了解图文、语音等场景的基本判断即可，优先练六大模块；不能把“不单列”理解为“题目绝不涉及”。

### 4. ⚠️ 官方不说「插件」，只说「工具」

官方大纲**全文 0 次「插件」**，统一用「**工具 / 工具调用**」。网传笔记和旧版课程里的「插件」是历史说法。
本库已全量替换。场景题按官方判据作答：

> **查企业资料 → RAG**　｜　**实时数据 / 确定性计算 / 业务动作 → 工具**

### 5. 别在「不考」的内容上花时间

官方明说：不考代码、**不考模型训练细节**、**MCP 不考协议细节**。
以下属于「了解即可」：LoRA / QLoRA / PEFT / 超参数数值 / 注意力机制推导 / MoE 结构细节 / MCP 握手与报文。
