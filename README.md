> 目标：不只过 80 分，而是建立一套能迁移到实际工作的大模型应用知识框架。

## 🗂 多维框架

```
                    ┌─────────────────────────┐
                    │  00 基准：考什么？考多少？  │  ← 一切的地基
                    └───────────┬─────────────┘
                                │
        ┌───────────┬───────────┼───────────┬───────────┐
        ▼           ▼           ▼           ▼           ▼
   ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
   │01 知识 │ │02 路径 │ │03 决策 │ │04 辨析 │ │05 冲刺 │
   │地图    │ │与课时  │ │树      │ │速查    │ │口诀    │
   │        │ │        │ │        │ │        │ │        │
   │知识点  │ │怎么学  │ │怎么选  │ │怎么不  │ │怎么记  │
   │清单    │ │按什么序│ │用哪个  │ │踩坑    │ │得住    │
```

## 🚀 怎么用

### 第一次进来，按这个顺序

1. 读 [`docs/00-考试基准-V2.4.md`](docs/00-考试基准-V2.4.md) —— 5 分钟，搞清楚权重
2. 打开 [`docs/01-知识地图-六大模块.md`](docs/01-知识地图-六大模块.md)，**诚实填完所有自评**
3. 根据自评结果，按 [`docs/02-课时与学习路径.md`](docs/02-课时与学习路径.md) 的顺序开始
4. 每学完一个模块，去 [`quiz/`](quiz/README.md) 做题验证
5. Agent 模块**必须**做 [`practice/`](practice/README.md) 的实验

### 日常学习循环

```
知识地图自评 → 定位薄弱模块 → 学/实操 → 做题 → 错题本 → 回填辨析表 → 再自评
```

## ⚠️ 三个已知坑（建库时已排查）

### 1. 网传笔记的课时编号是旧版

`Aliyun-ACA-LLM-Study-Summary`（2026-05，GitHub 6 stars）用的课时结构与 V2.4 **完全错位**：

| 课时 | 旧版笔记 | V2.4 官方 |
|:---:|---|---|
| 3 | API 调用 | **提示词优化** |
| 5 | 插件 | **微调** |
| 6 | RAG | **桌面 Agent** |
| 8 | 智能体 | **Skill 编排** |
| 9 | 安全合规 | **自检闭环** |
| 10 | 多模态 | **安全合规** |

→ 知识点可用，**编号不能照抄**。详见 [`docs/02-课时与学习路径.md`](docs/02-课时与学习路径.md)。

### 2. 网传资料缺 V2.4 全部新增考点

桌面 Agent、知识库应用、MCP、Skill 编排、自检闭环、RAG 评测归因、向量检索 —— 旧笔记里**一个都没有**。
而这些正好是本次提分最多的部分（Agent +6%）。

### 3. 「多模态大模型」已不再单独考核

旧资料还在讲多模态（原 6%），V2.4 已移除、整合进其他章节。别在这上面花时间。
