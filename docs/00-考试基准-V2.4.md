## 四、V2.4 新增考点（决定复习重心）

### 增强大模型应用的能力（20% → 22%）
- 新增 **RAG 评测归因**
- 新增 **向量检索**

### 大模型 Agent（10% → 16%，本次升级最大变量 ⭐）
- 新增 **桌面 Agent**（本地安装与执行）
- 新增 **知识库应用**
- 新增 **MCP 协议**
- 新增 **Skill 编排**
- 新增 **自检闭环**

### 配套课程同步迭代
- 新增交互式演示：**文字接龙、分词、注意力溯源**
- 强化图文说明：**大模型基础原理、注意力机制、MoE 架构**
- 原「拓展学习」独立章节被**拆分融入**对应知识点，**不再单独考核**

### 一句话结论
> V2.4 的核心变化是：**考核重心从「理论概念」转向「实际落地」，Agent 从边缘模块变成第二梯队拉分点。**
> 官方课时 6-9（桌面 Agent / 知识库与工具 / Skill / 自检闭环）占了第 2 章 8 个课时中的 4 个，正是这 16% 的载体。
