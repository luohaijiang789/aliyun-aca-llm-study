# 题主顺序题 1～150 考点复盘

> 2026-10-09 逐题查看前 150 题后整理。本文转述考点，不复刻第三方题库原文。多数页面未展开标准答案，因此以下结论按教材原理校正；1、2、150 的答案已在页面直接核验。

## 命题特征

- 重点是业务场景判断：最先做什么、哪种方案合适、哪项无关或不能解决。
- 覆盖模型、Prompt、RAG、Agent、微调、多模态、安全和部署，深度以概念边界与方案选择为主。
- 多选题偏爱完整闭环；“完全、始终、全部统一、只需、无需审核、越大越好”多为干扰表述。
- 题库存在旧模型、旧案例或不严谨表述，需按题干语境答题，并以官方资料校准。

## 必补的 12 组知识

1. RAG：切分 → 嵌入 → 召回 → 过滤 → 重排 → 上下文 → 生成 → 引用与评估。
2. Agent：规划、记忆、工具、执行、反馈；多 Agent 增加角色分工、共享状态和冲突协调。
3. 预训练、SFT、RLHF：通用能力、任务适配、偏好对齐。
4. Prompt：角色、上下文、示例、格式、约束、CoT；不修改权重。
5. 安全：个人信息、权限、插件越权、非法查询、评测与审核。
6. 数据：合法来源、清洗、去重、脱敏、标注一致、集合隔离。
7. 评估：P/R/F1/AUC 与 MSE；线上还看时延、成本、稳定性、安全。
8. 优化：梯度下降、初始化、BN、正则化、学习率、过拟合、梯度消失。
9. 多模态：表示、对齐、融合、视觉、ASR、TTS 和跨模态生成。
10. GAN 与扩散：对抗训练对比逐步去噪。
11. 部署：容器、负载均衡、灰度、版本、监控、回滚、推理加速。
12. 选型：效果、数据、成本、时延、许可、安全、可维护性共同决策。

## 场景题五步法

1. 先看目标是质量、速度、成本、安全还是可解释性。
2. 再定位数据、训练、Prompt、检索、Agent、部署或治理环节。
3. 检查个人信息、插件、联网、知识边界和自主执行风险。
4. 排除“完全、所有、只需、无需人工、越大越好”等绝对表述。
5. 优先选择覆盖需求、数据、方案、评估、上线、监控的完整闭环。
