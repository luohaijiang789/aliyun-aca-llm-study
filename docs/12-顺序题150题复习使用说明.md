## 三轮复习法

### 第一轮：建立边界

逐题作答。答错后不要抄答案字母，只写一句规则，例如“Prompt 改输入，不改权重”“RAG 阈值越高通常召回越少”。

### 第二轮：按错因重组

- 反向题：先圈“不正确、不能、不包括”。
- 绝对化表述：重点审查“完全、仅、所有、自动、无需”。
- 多选边界：每个选项独立判断，避免因为主题相关就全选。
- 产品归属：模型、公司和技术路线分别记忆。

### 第三轮：场景决策

遇到业务题按“目标 → 数据 → 方案 → 评估 → 上线治理”判断；遇到 RAG、Agent、微调题先确定问题发生在哪一层。

## 题库口径高风险题

以下题目的题库答案或表述容易与教材常识产生冲突，考试前应记住题库口径，同时掌握标准概念：

- **41（ABCD）**：Few-shot 选代表性样例并反馈、A/B 测试，不是越多越好。
- **44（BC）**：上下文按相关性、时效性保留、更新、摘要或淘汰。
- **94（B）**：预处理含清洗、标准化、异常处理、分词和特征处理。
- **99（B）**：指令微调更新模型参数；提示方法优化输入或少量提示参数。
- **101（D）**：优化目标是改善目标性能；训练时间和复杂度是约束。
- **103（ABCDE）**：插件和第三方 API 直接扩展 Agent 行动能力。
- **110（ABD）**：分词将文本切成 token；子词分词不等于中文单字切分。
- **115（AD）**：多模态可联合处理文本、图像、语音并理解或生成。
- **117（ABCD）**：优质 Prompt 可给样例、业务背景、规范用语；不能强制模型真有“思维链”。
- **123（C）**：L1、Dropout、早停均可抑制过拟合；单选时留意教材口径。
- **135（A）**：区分正式政策文件与新闻发布活动，关注 AI 与实体经济政策语境。
- **147（A）**：二分、分箱、聚类可离散化；PCA 是降维。

## 每天的具体安排

1. 新做 30 题。
2. 把错题按模块和陷阱类型登记。
3. 当天重做错题一次。
4. 隔天只重做错题。
5. 最后一天只看高风险题和判断规则。
