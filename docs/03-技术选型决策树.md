## 一、官方六选一手段池（先背这个）

> 官方原文（考试重点段）：
> 「能在业务场景中选择合适的方法：**优化输入、接入知识库、调用工具、使用微调、协作 Agent，或保留人工确认**。」

```
① 优化输入（提示词）      —— 成本最低，永远先试
② 接入知识库（RAG）       —— 查企业资料 / 私域知识
③ 调用工具                —— 实时数据 / 确定性计算 / 业务动作
④ 使用微调                —— 稳定行为 / 格式 / 风格 / 分类能力
⑤ 协作 Agent              —— 从「回答问题」推进到「完成任务」
⑥ 保留人工确认            —— 高风险、不确定、需担责
```

⚠️ 术语口径：官方大纲统一说法是「**工具 / 工具调用**」，全文未出现其他旧称。考试中看到「工具」不要犹豫。

## 二、判据对照表（场景题的直接答案）

| # | 场景判据（题干里的信号词） | 应选手段 | 官方依据 |
|:---:|---|---|---|
| ① | 回答质量不够好、表述不对、不够聚焦、缺目标/背景/约束 | **优化输入（提示词）** | 考试内容 2「好答案来自好输入」；成本最低，永远先试 |
| ② | 要查**企业资料 / 私域知识 / 内部文档** | **接入知识库（RAG）** | 考试内容 3「查企业资料用 RAG」 |
| ③ | 要**实时数据**、**确定性计算**、**业务动作**（下单、发邮件、改系统状态） | **调用工具** | 考试内容 3「需要实时数据、确定性计算或业务动作时用工具」 |
| ④ | 要**稳定行为 / 格式 / 风格 / 分类能力**，或**支持轻量模型部署** | **微调** | 考试内容 4 |
| ⑤ | 要从「**回答问题**」推进到「**完成任务**」（多步执行、自主规划） | **协作 Agent** | 考试内容 5「Agent 的价值是把『回答问题』推进到『完成任务』」 |
| ⑥ | **高风险**、不确定、需担责（医疗、金融、合同、对外发布） | **保留人工确认** | 考试重点段；考试内容 5「高风险动作必须人工确认」、考试内容 6 |

> 🔑 **一句话总纲（官方原文 · 考试内容 4）**：
> **「查知识用 RAG，做动作靠工具，稳行为才考虑微调。」**

## 三、判断流程图（按官方判据走）

```
                     业务场景：效果不够好 / 做不到
                                │
                    ┌───────────┴───────────┐
                    │ 第 1 问：是"说不清"还是"做不到"？│
                    └───────────┬───────────┘
                                │
              ┌─────────────────┴─────────────────┐
              ▼                                   ▼
      【表达 / 输入问题】                    【知识 / 能力问题】
      模型听得懂，只是答得糙                模型根本不知道或做不到
              │                                   │
              ▼                                   │
   ① 优化输入（提示词）                            │
      讲清目标/背景/角色/约束/示例                  │
      输出格式/评价标准                            │
              │                                   │
       还不够好 ↓                                  ▼
              │                    ② 第 2 问：缺的是什么？
              │                          │
              │        ┌────────┬────────┼────────┬────────┐
              │        ▼        ▼        ▼        ▼        ▼
              │    企业资料  实时数据  稳定格式  多步执行  高风险
              │    私域知识  确定性   风格分类  完成任务  需担责
              │    内部文档  计算     轻量部署          不确定
              │        │    业务动作      │        │        │
              │        ▼        ▼        ▼        ▼        ▼
              └─────→ ② RAG   ③ 工具   ④ 微调   ⑤ Agent  ⑥ 人工确认
                   接入知识库 调用工具 使用微调 协作Agent 保留人工
              （可组合：如 RAG 补知识 + 微调定风格 + Agent 编排）

      ⚠️ ⑥ 保留人工确认不是"最后兜底"，而是贯穿全程：
         只要出现高风险动作，就必须叠加人工确认。
```

## 四、六选一对照表（背下来）

| 手段 | 解决什么 | 不解决什么 | 成本 | 对应模块 / 权重 |
|---|---|---|---|:---:|
| **优化输入（提示词）** | 表达不清、指令模糊、输出不稳定 | 缺知识、缺能力 | 💰 最低 | M2 提示词工程 20% |
| **接入知识库（RAG）** | 缺**企业资料 / 私域知识**、幻觉 | 执行动作、格式风格 | 💰💰 | M3 增强应用 22% |
| **调用工具** | **实时数据、确定性计算、业务动作** | 知识组织、流程编排 | 💰💰 | M3 增强应用 22% |
| **使用微调** | **稳定行为 / 格式 / 风格 / 分类能力**、轻量部署 | 知识更新（会过时）、能力扩展 | 💰💰💰 | M5 微调 12% |
| **协作 Agent** | 从「回答问题」推进到「**完成任务**」、多步执行 | 简单单轮问答（杀鸡用牛刀） | 💰💰💰 | M4 Agent 16% |
| **保留人工确认** | 高风险、不确定、需担责的场景 | 效率问题 | — | M4 Agent 16% / M6 安全合规 12% |

## 五、高频陷阱辨析（按官方口径纠正）

| 陷阱说法 | 正解 |
|---|---|
| 「模型不知道我们公司内部资料，应该微调」 | ❌ **查知识用 RAG，稳行为才考虑微调**。微调是把知识写进权重，会过时且不可追溯 |
| 「回答格式不统一，用 RAG 解决」 | ❌ 格式 / 风格统一属于**稳定行为**，走微调（先试提示词强约束） |
| 「要查今天的股价 / 天气，用 RAG」 | ❌ 这是**实时数据** → **调用工具**。RAG 的库是你自己喂的静态知识 |
| 「要让系统自动下单 / 发邮件，用 RAG」 | ❌ 这是**业务动作** → **调用工具**；若多步串联则再上 Agent |
| 「算一笔精确的金额，让模型直接算」 | ❌ **确定性计算** → **调用工具**，模型擅长生成不擅长精确计算 |
| 「任务只要三步，上 Agent」 | ⚠️ 简单任务优先**优化输入 + 任务拆解**，Agent 有成本与不确定性 |
| 「效果不好就直接微调」 | ❌ **微调不是万能按钮**。顺序不能跳：优化输入 → RAG / 工具 → 微调 / Agent |
| 「RAG 和微调二选一」 | ❌ 可组合：RAG 补知识 + 微调定风格 |
| 「Agent 能全自动，不用人管」 | ❌ **高风险动作必须人工确认**；「AI 可以辅助整理和起草，但不能替代最终责任人」 |

## 六、一句话记忆（官方版）

> ### **「查知识用 RAG，做动作靠工具，稳行为才考虑微调。」**（官方原文 · 考试内容 4）
>
> 拆解：
> - **查知识** → 企业资料 / 私域知识 → **RAG（接入知识库）**
> - **做动作** → 实时数据 / 确定性计算 / 业务动作 → **调用工具**
> - **稳行为** → 稳定格式 / 风格 / 分类能力 → **才考虑微调**
>
> 前半句补一句更好记：**「说不清先优化输入，要完成多步任务上 Agent，高风险留人工确认。」**

⚠️ 旧版口诀已废止 —— 官方判据是「**需要实时数据、确定性计算或业务动作 → 调用工具**」。

## 七、场景自测（答案在文末）

1. 客服机器人不知道公司最新的退货政策（政策上周刚改）→ ？
2. 模型输出的 JSON 时而是对象时而是数组，格式不稳定 → ？
3. 需要模型读一个 Excel、算总和、再写一封邮件发出去 → ？
4. 需要查询实时的股票价格 → ？
5. 模型回答泛泛而谈、不够聚焦 → ？
6. 让模型用「法务合规部」的口吻写对外回复，且每次语气一致 → ？
7. 模型不知道 2026 年新发布的行业法规 → ？
8. 要让 Agent 自动向客户发送合同并归档，法务要求发前必须有人点头 → ？
9. 医疗场景下 AI 起草了一份患者告知书 → ？

<details>
<summary>答案（官方口径）</summary>

1. **接入知识库（RAG）** —— 「查企业资料用 RAG」；微调进去的知识会立刻过时
2. **优化输入（提示词强约束）先试** → 仍不稳再 **微调**（稳定输出格式）
3. **协作 Agent** —— 从「回答问题」推进到「完成任务」；其中读文件、计算、发信靠**调用工具**
4. **调用工具** —— 实时数据（官方判据第一条）
5. **优化输入（提示词）** —— 「好答案来自好输入」，加目标、背景、约束、示例
6. **微调** —— 稳定行文风格是微调的典型场景（「稳行为才考虑微调」）
7. **接入知识库（RAG）** —— 时效知识靠检索；法规更新了改库即可，不用重训
8. **协作 Agent + 保留人工确认** —— 「高风险动作必须人工确认」
9. **保留人工确认** —— 医疗属高风险场景，「AI 可以辅助整理和起草，但不能替代最终责任人」

</details>
