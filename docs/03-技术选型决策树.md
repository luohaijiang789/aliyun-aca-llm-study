# 03 · 技术选型决策树（必考场景题）

> ACA 最爱出的题型：「某某场景下，应该用什么手段？」—— 本质考 **成本递增顺序**。
> 记住一条主线：**先便宜后贵，先软后硬。**

---

## 主决策树

```
                大模型回答不够好
                        │
        ┌───────────────┴───────────────┐
        │  第 1 问：是「说不清」还是「不知道」？  │
        └───────────────┬───────────────┘
                        │
        ┌───────────────┴───────────────┐
        ▼                               ▼
   【表达/理解问题】              【知识/能力问题】
   模型听得懂，只是答得糙         模型根本不知道或做不到
        │                               │
        ▼                               │
   ① 优化提示词                          │
   成本最低，永远先试                     │
        │                               │
        │ 还不够好                        │
        ▼                               ▼
   ② 看缺什么 ─────────────────────────┐
        │                              │
   ┌────┴─────┬──────────┐             │
   ▼          ▼          ▼             ▼
 缺私域/    需要固定     任务复杂     能力边界不足
 最新知识   格式/风格    多步执行     （联网/计算/
   │          │         调外部API     操作系统）
   ▼          ▼          ▼             ▼
 ③ RAG     ④ 微调     ⑤ Agent       ⑥ 插件
```

---

## 五选一对照表（背下来）

| 手段 | 解决什么 | 不解决什么 | 成本 | 对应模块/课时 |
|---|---|---|---|:---:|
| **优化提示词** | 表达不清、指令模糊、输出不稳定 | 缺知识、缺能力 | 💰 最低 | 提示词工程 20% / 课时3 |
| **RAG** | 缺私域知识、缺最新信息、幻觉 | 格式风格、执行动作 | 💰💰 | 增强应用 22% / 课时4 |
| **微调** | 固定输出格式、行文风格、领域表达习惯 | 知识更新（会过时）、能力扩展 | 💰💰💰 | 微调 12% / 课时5 |
| **Agent** | 复杂多步任务、需调用工具/API、需自主规划 | 简单单轮问答（杀鸡用牛刀） | 💰💰💰 | Agent 16% / 课时6-9 |
| **插件** | 模型本身能力边界外的事（联网、计算、查实时数据） | 知识组织、流程编排 | 💰💰 | 增强应用 22% |

## 高频陷阱辨析

| 陷阱说法 | 正解 |
|---|---|
| 「模型不知道我们公司内部资料，应该微调」 | ❌ 微调是改**风格**，补知识用 **RAG**。微调进权重的知识会过时且不可追溯 |
| 「回答格式不统一，用 RAG 解决」 | ❌ 格式/风格统一用 **微调**（或提示词里强约束） |
| 「要查今天天气，用 RAG」 | ❌ 实时外部能力用 **插件**。RAG 的库是你自己喂的静态知识 |
| 「任务只要三步，上 Agent」 | ⚠️ 简单任务优先**提示词 + 任务拆解**，Agent 有成本与不确定性 |
| 「效果不好就直接微调」 | ❌ 顺序不能跳。**提示词 → RAG/插件 → 微调/Agent**，成本递增 |
| 「RAG 和微调二选一」 | ❌ 可组合：RAG 补知识 + 微调定风格 |

---

## 一句话记忆

> **「先问再说，缺知检索，定风微调，多步智能，越界插件。」**
>
> 拆解：
> - 先问再说 → 先优化提示词
> - 缺知检索 → 缺知识用 RAG 检索
> - 定风微调 → 定风格用微调
> - 多步智能 → 多步骤用 Agent（智能体）
> - 越界插件 → 超出模型能力边界用插件

## 场景自测（答案在文末）

1. 客服机器人不知道公司最新的退货政策（政策上周刚改）→ ？
2. 模型输出的 JSON 时而是对象时而是数组，格式不稳定 → ？
3. 需要模型读一个 Excel、算总和、再写一封邮件发出去 → ？
4. 需要查询实时的股票价格 → ？
5. 模型回答泛泛而谈、不够聚焦 → ？
6. 让模型用「法务合规部」的口吻写对外回复，且每次语气一致 → ？
7. 模型不知道 2026 年新发布的行业法规 → ？

<details>
<summary>答案</summary>

1. **RAG**（最新私域知识）—— 微调进去的知识会立刻过时
2. **提示词强约束**（先试）→ 不行再 **微调**（固定格式）
3. **Agent**（多步 + 调工具）
4. **插件**（实时能力，模型本身不具备）
5. **优化提示词**（加角色、加约束、加示例）
6. **微调**（固定行文风格，这是微调的典型场景）
7. **RAG**（时效知识）—— 除非考的是"法规更新后要重新微调"这个陷阱，记住：知识用检索

</details>
