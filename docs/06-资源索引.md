## 五、抓取方法备忘

`chat.qwen.ai` 等分享页为客户端渲染，`curl` 只能拿到空壳。有效方法：

```bash
# Playwright（本环境 venv 已装）
/Users/lhj/.workbuddy/binaries/python/envs/default/bin/python <script>.py
```

要点：`goto` → 等 5s → 点击 `+N` 折叠按钮展开 → 滚动触发懒加载 → JS 遍历 DOM 抽文本。
