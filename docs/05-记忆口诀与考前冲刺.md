## 二、核心口诀

### 训练三阶段
> **「预训练打底子，SFT 学听话，RLHF 学做人。」**
> 预训练 = 学知识｜SFT = 学指令｜RLHF = 学价值观

### 技术选型（官方版 · 替换旧版非官方说法）
> **「说不清先优化输入，查知识用 RAG，做动作靠工具，稳行为才微调，要完成多步任务上 Agent，高风险必须人工确认。」**

- 说不清 → **优化输入（提示词）**，成本最低，永远先试
- 查知识 → **接入知识库（RAG）**：企业资料 / 私域知识
- 做动作 → **调用工具**：实时数据 / 确定性计算 / 业务动作
- 稳行为 → **微调**：稳定格式 / 风格 / 分类能力 / 轻量部署
- 多步任务 → **协作 Agent**：从「回答问题」推进到「完成任务」
- 高风险 → **保留人工确认**

⚠️ 旧版口诀已废止 —— 官方判据是「**需要实时数据、确定性计算或业务动作 → 调用工具**」。

### Agent 三能力
> **「感知收信息，思考做规划，行动调工具。」**

### Agent 四要素
> **「目标、资料来源、工具边界、阶段检查点。」**（官方原文 · 考试内容 5）

### 微调（只记流程与边界）
> **「定义目标、准备样本、选择基模、控制数据质量、评估效果。」**（官方五步流程）
> ⚠️ LoRA / QLoRA 等训练细节**不考**，见下方「不考清单」。

### 安全合规七项治理
> **「内容安全、数据安全、权限控制、生成内容标识、来源留存、审计追踪、人工复核。」**（官方原文 · 考试内容 6）

### 高风险四类场景
> **「医疗、金融、合同、对外发布」** —— 一律人工确认 + 人工复核

## 四、⚠️ 不考清单（避免过度复习）

> 官方声明：**本认证不要求考生编写代码，也不考模型训练和协议实现细节**；MCP **只考作用，不要求掌握协议细节**。

| 内容 | 处理 |
|---|---|
| **LoRA / QLoRA / PEFT** 原理与差异 | 了解即可，**不考** |
| **超参数**配置与调优 | 了解即可，**不考** |
| **注意力机制**推导（Q/K/V 计算） | 了解即可，**不考** |
| **MoE 结构**细节 | 了解即可，**不考** |
| **MCP 协议**细节 | 只考**作用与定位**，**不考协议** |
| **编写代码**、控制台操作步骤 | 明确**不考** |
| **模型训练**实现细节 | 只考「适用场景 + 基本流程」，**不考训练细节** |

**✅ 该花时间的是**：官方六选一判据、五句金句、RAG 五环节（解析/切分/检索/重排序/评测）、Agent 四要素、微调五步流程、安全合规七项治理。

## 六、考场策略

| 题型 | 数量 | 策略 |
|---|---|---|
| 单选 35 题 | 70 分 | 主战场。**排除法**优先，绝对化表述（"一定""所有""只能"）多半是错的 |
| 多选 15 题 | 30 分 | **保守原则**：不确定就少选。少选得部分分，错选可能全扣（以官方规则为准） |

**时间分配**（60 分钟）
```
单选 35 题  →  35 分钟（60 秒/题）
多选 15 题  →  18 分钟（72 秒/题）
检查        →   7 分钟
```

**答题优先级**
1. 会做的立刻做，不纠结
2. 卡住的标记跳过，最后回头
3. 多选题拿不准时，回到「技术选型决策树」判断出题人想考哪个手段
4. 场景题先找**官方判据词**：企业资料→RAG；实时/计算/动作→工具；格式风格→微调；多步→Agent；高风险→人工确认
